銀行振込決済とは：お店が銀行振込を受ける方法と、消込のいらない受け取り方

銀行振込決済は、ネットショップなどで、購入者が銀行振込で代金を払う決済方法です。お店の口座で直接受ける方法と、決済サービスを通して受ける方法があり、決済サービスを使うと入金の照合の多くを任せられます。お店の側で消込そのものをなくすには、支払いが最初から注文に結びつく受け取り方を選びます。日本円の銀行振込で用意したステーブルコインで、注文ごとに受け取る方法もその一つです。

3 行でわかる

  • 銀行振込決済は、購入者が銀行振込で代金を払う決済方法です。お店の口座で受ける方法と、決済サービスを通す方法があります。
  • 決済サービスを使うと、入金の照合の多くを任せられます。過不足の入金や返金の扱いは、サービスによって違います。
  • 消込をなくすには、支払いが最初から注文に結びつく受け取り方が要ります。

銀行振込決済とは

すてぶるくん：銀行振込で払うのが、銀行振込決済？

すてぶるちゃん：そうです。購入者が自分で振り込み、お店は入金を確かめてから発送します。

銀行振込決済は、購入者が銀行振込で代金を払う決済方法です。前払いが中心で、購入者が自分で振り込み、お店は入金を確かめてから、商品を発送したりサービスを提供したりします。

日本円の銀行振込には、カードのような、購入者の申し立てによる一方的な取り消しの仕組みはありません。Stripe のドキュメントは、銀行振込による支払いは、USD と CAD を除き、購入者の申し立てでは取り消せないと書いています[1]。お店から返金することはできます。カードの取り消しの仕組みは、チャージバックとはで解説しています。

お店の手間は、入金の確認にあります。入金を注文と照合して、注文を入金済みにする作業が、入金消込（消込）です。やり方と手間のかかる理由は、入金消込とはで解説しています。

銀行振込の受け取り方を比べる

お店が銀行振込を受ける方法は、大きく 3 つあります。入金確認、消込、ずれ、返金の違いを、一般的な傾向でまとめます。Shopify・Stripe・BASE の例は、各社の公式ドキュメントとヘルプの記載です。条件は、提供元ごとに違います。

銀行振込から使えるステーブルコイン決済（すてぶるペイの形） 購入者は、JPYC EX の画面に出る口座へ振り込む。お店の口座ではない。 お店が注文ごとに金額と注文番号を登録して決済を作るため、入金の明細と注文を突き合わせる消込は要らない。 承認された金額が送られ、手数料は同じ取引の中で差し引かれる。注文の額より多く用意した JPYC の余りは購入者のウォレットに残り、一部だけが届くことはない。 成立の知らせが、注文番号つきでお店のサーバーに届く。届かないときは、お店のサーバーから決済の状態を照会する。 お店の owner が、加盟店コンソールでパスキーで承認し、元の支払人のウォレットへ送る。購入者の銀行口座の情報は要らない。 開発中で、提供開始日は未定です（2026年11月時点）。購入者は JPYC EX のアカウントが必要。

お店の口座で直接受ける

お店の口座があれば受け取れるため、決済サービスとの契約が要りません。一方で、照合はお店の作業です。入金の明細を見て、どの注文の支払いかを調べ、注文を支払い済みにします。Shopify の手動の支払いも、お店が入金を確かめたあとに、注文を支払い済みにする形です[2]。

件数が増えるほど、突き合わせの手間も増えます。名義が注文者と違う入金や、手数料を引いた額の入金は、お店が調べます。振込名義の前に注文番号を入れてもらうと、探しやすくなります。購入者が入れ忘れたときは、金額や名前から探します。合わない入金の例と減らし方は、入金消込とはにまとめています。

決済サービスの銀行振込

決済サービスの銀行振込は、振込先の口座を分けて、入金の照合を自動にします。仕組みは次のとおりです。

  • BASE。注文によって振込先の口座番号が違います。振込先の口座・入金額・振込人名義の前の 4〜5 桁の識別コードで、自動で入金確認をします[3]。入金確認の目安は、銀行の営業時間内の支払いで 2 時間前後、それ以外は翌営業日の午前中です[4]。
  • Stripe。顧客ごとに仮想口座を作ります。ドキュメントの例では、振込先の口座名義は Stripe の収納代行の名義です[5]。日本円は、仮想口座で顧客を特定したうえで、顧客の現金残高と金額が一致する 1〜5 件の請求書・PaymentIntent の組み合わせを探します。なければ、全額を充てられる請求書を確定日時の古い順に充て、残りを PaymentIntent の確認日時の古い順に充てます[6]。

それでも残ることがあります。BASE では、識別コードを入れ忘れると、手動の確認になり、時間がかかります[3]。Stripe では、過払いは顧客の残高に残ります[5]。照合されない資金が 75 日を超えて残ると、顧客の銀行口座への返金が自動で試みられ、90 日を過ぎても残っていれば Stripe の残高に移ります。消し込まれているかを確かめる責任は、お店にあると書かれています[1][6]。

銀行口座へ返金するには、購入者の口座の情報が要ります。Stripe では、振込のときに受け取った口座の情報を使い、無いときやあいまいなときは Stripe が購入者にメールで尋ねます[9]。BASE は、入金後の注文はキャンセルできず、ショップから購入者へ返金するよう案内しています[7]。銀行 API やバーチャル口座で自動にできることと、例外として残る作業は、入金消込は自動化できる？で解説しています。決済代行の仕組みは、決済代行とはにまとめています。

消込のいらない受け取り方の条件

すてぶるくん：消込のいらない受け取り方って、あるの？

すてぶるちゃん：条件が 3 つあります。支払いの前に注文が決まっていて、振り込む額の過不足がお店の受け取りに及ばず、成立が注文番号つきで届くことです。

入金の明細を注文と突き合わせる作業がなくなるのは、次の 3 つがそろうときです。

  1. 支払いの前に、金額と注文が決まっている。支払いが、最初から特定の注文のものになります。
  2. 購入者が振り込む額の過不足が、お店の受け取りに及ばない。照合できない入金が、お店の側に残りません。
  3. 成立が注文番号つきで届き、お店が注文に反映できる。どの注文の支払いかを、お店が調べる必要がなくなります。届かないときは、お店のサーバーから状態を照会して確かめます。

決済サービスの仮想口座も、自動の照合や支払いの通知を用意しています。過不足のある入金の扱いは、サービスによって違います。BASE では、不足は購入者が BASE へ追加で振り込み、過入金は BASE から購入者へ返金します（返金の手数料は購入者の負担）[8]。Stripe では、照合されない資金が消し込まれているかを確かめる責任はお店にある、とドキュメントにあります[1]。

お店の口座で直接受ける銀行振込は、振り込む額も名義も購入者しだいのため、この 3 つを満たしにくい方法です。どれかが欠けると、合わない入金を、決めたルールで処理するか、購入者に連絡して確かめる作業が残ります。

すてぶるペイの場合：消込のいらない銀行振込

すてぶるペイは、円で払い、ステーブルコイン（JPYC）で受け取る決済です。開発中で、提供開始日は未定です（2026年11月時点）。購入者は日本円の銀行振込とパスキーで支払い、お店は注文ごとに売上を受け取ります。流れは次のとおりです。

  1. お店のサーバーが、注文ごとに金額と注文番号を登録して、決済を作ります。
  2. 購入者は、決済ページで支払いの内容をパスキー（顔・指紋認証）で承認します。JPYC の残高が足りないときは、JPYC EX（JPYC の発行と交換を行うサービス）で発行を申し込み、JPYC EX の画面に出る口座へ日本円を銀行振込します。振込を確かめて JPYC を発行するのは JPYC EX です。
  3. 支払える額がそろうと、承認された金額の JPYC が、購入者のウォレットからお店の受取ウォレットへ送られます。手数料は、同じ取引の中で差し引かれます。
  4. 成立の知らせ（Webhook）が、注文番号つきでお店のサーバーに届きます。届かないときは、お店のサーバーから決済の状態を照会して確かめます。

お店に届くのは注文ごとの支払いなので、入金の明細を注文と突き合わせる消込は要りません。ここでいう消込が要らないとは、銀行の入金明細と注文を突き合わせる作業がない、という意味です。注文の額より多く JPYC を用意した場合は、支払いのあとの余りが購入者のウォレットに残り、次のお支払いに使えます。期限までに支払える額がそろわなければ、決済は失効し、お店には何も届きません。一部だけが届くことはありません。返金は、お店の owner が加盟店コンソールでパスキーで承認し、元の支払人のウォレットへ送ります。購入者の銀行口座の情報は要りません。

注意点もあります。購入者は、JPYC EX のアカウント（個人は日本在住の方）が必要で、初回は JPYC EX での本人確認があります。お店が受け取るのは JPYC で、日本円にするには JPYC EX で償還（日本円に戻すこと）します。お店の側でも、成立の知らせを注文に反映する組み込み（知らせの署名の検証や、届かないときの状態照会）と、返金の操作は残ります。状態を照会しても結果が確定しない場合は、注文を保留して調査を依頼します（異常系の扱い）。売上と手数料の記帳は残るので、会計の扱いは税理士に確かめてください。利用には、利用規約への同意と、法令上の要件を満たすことが前提です。お金の流れの詳細は、加盟店向けドキュメントのお金の流れと返金の提供範囲にあります。

選び方

どの方法が合うかは、件数と、売るものによって変わります。

  • 件数が少ないうち。自分の口座でも回ります。名義に番号を入れてもらう工夫で、確認の手間を抑えられます。
  • 件数が増えたら。決済サービスで、入金の照合を自動にします。過不足や返金の扱いはサービスによって違うため、事前に確かめておきます。
  • デジタル商品など、すぐ届けたいもの。名義や金額のずれをなくしたいもの。注文ごとに成立する方法が向きます。お店が入金を確かめなくても、成立の知らせを受けて届けられます。

カードや他の方法との組み合わせは、ネットショップの決済方法 9 種類を比較で、費用の比べ方は、決済手数料の比較と計算方法で解説しています。

よくある質問

銀行振込決済とは何ですか？

購入者が銀行振込で代金を払う決済方法です。多くは前払いで、お店は入金を確かめてから、商品を発送したりサービスを提供したりします。お店の口座で直接受ける方法と、決済サービスを通して受ける方法があります。

銀行振込の決済代行や決済サービスを使うと、何が変わりますか？

注文ごとや顧客ごとに振込先の口座番号を分けて、入金の照合を自動にできます。たとえば BASE は、振込先の口座・入金額・振込人名義の前の識別コードで、自動で入金確認をします。ただし、過不足のある入金や返金の扱いは、サービスによって違います。決済代行の仕組みは、決済代行の解説にまとめています。

決済サービスを使えば、消込は要らなくなりますか？

照合の多くは自動になりますが、なくなるわけではありません。BASE では、識別コードの入れ忘れは手動の確認になり、時間がかかります。Stripe の銀行振込では、照合されない資金が残ることがあり、消し込まれているかを確かめる責任はお店にあると書かれています。

銀行振込で返金するときは、どうしますか？

銀行口座へ返金するには、購入者の口座の情報が要ります。Stripe では、振込のときに受け取った口座の情報を使い、無いときやあいまいなときは Stripe が購入者にメールで尋ねます。BASE は、入金後の注文はキャンセルできず、ショップから購入者へ返金するよう案内しています。日本円の振込には、購入者の申し立てで一方的に取り消す仕組みはありません。

振込名義が違う入金は、どう扱いますか？

名義が注文者と違うと、名前だけでは注文と結びつけられません。金額や入金日から候補を探し、必要なら購入者に連絡して確かめます。名義の前に識別コードを入れてもらう方法や、注文ごとに振込先の口座を分ける方法で、減らせます。詳しくは入金消込の解説にまとめています。

消込のいらない銀行振込の受け取り方はありますか？

支払いの前に金額と注文が決まっていて、購入者が振り込む額の過不足がお店の受け取りに及ばず、成立が注文番号つきで届く方法なら、銀行の入金明細と注文を突き合わせる作業はなくなります。すてぶるペイは、この形で受け取る決済です。開発中で、提供開始日は未定です（2026年11月時点）。購入者は JPYC EX のアカウント（個人は日本在住の方）が必要です。
