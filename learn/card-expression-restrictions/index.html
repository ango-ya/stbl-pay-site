クレカ・カード会社の表現規制はなぜ？理由と同人・成人向け作品の決済の備え

カード会社の表現規制（クレカの表現規制、金融検閲とも呼ばれます）とは、法律とは別に、国際カードブランドやアクワイアラー・決済代行会社の規則と判断で、合法な作品のカード決済が止まることです。割賦販売法は、取扱商材の表現内容を規制していません（経済産業省の国会答弁）。ただし、刑法175条や児童ポルノ禁止法などで違法な表現物は、どの決済手段でも違法です。販売者にできるのは、決済手段を一つに頼らないこと、申込先の取扱方針を事前に確かめること、止まったときの案内を用意することです。

カード会社の表現規制で何が起きたのか：決済が止まった事例の年表

日本で合法な作品の決済が、カードブランドや決済代行会社の判断で止まった事例があります。報道で確かめられた範囲を、日付順にまとめます。理由を各社が公表していないものは、非公表と書きます。同人誌や同人ゲームのような創作物を扱う販売サイトや、投稿サービスが中心で、いずれも各社の発表や報道にもとづきます。

止まり方は一様ではありません。カードブランドの一部だけを止めた例、決済そのものではなく作品の閲覧や検索から外した例、一定期間だけ止めた例があります。共通するのは、法律で禁じられていない作品が対象になりうること、そして購入者が使い慣れたカードで払えなくなる点です。販売者にとっては、ある日突然、売り場の入口にあたる決済が使えなくなる事態になりえます。

カード決済の契約の仕組み

お店がカード決済を受け付けるときは、国際カードブランド（Visa、Mastercard など）の規則のもとで、お店は、加盟店と契約するアクワイアラーと直接契約する場合と、その契約を取り次ぐ決済代行会社を介して加盟店契約を結ぶ場合があります[8]。仕組みは決済代行とはで説明しています。

割賦販売法は、カード番号等の取扱契約を結ぶ登録事業者に、契約の前と、契約後も定期的に、または必要に応じて、お店を調べることを求めています。調べるのは、カード番号等の適切な管理や不正利用の防止に支障がないかです[18]。どんな商材を取り扱うかは、各社の規則と判断で決まります。カード決済は、鎖のどこか一つの会社が取り扱いをやめると、その先のお店は使えなくなります。

決済代行会社は、お店との契約の中で、取り扱えない商材や、利用を止める条件を定めています。申込のときに通っても、あとから取り扱いが変わる可能性は残ります。個々の事例の理由は非公表のため、どの会社のどの規則が働いたのかは、外からは確かめられません。

Visa・Mastercard などの規則と各社の判断

Visa の担当者は、2024年8月1日に米国本社で会った山田太郎参議院議員に、「取引については、合法、非合法の法的判断は行っているが、合法であるコンテンツなどに対する価値判断は行っていない」と述べた、と同議員が X で公表し、ITmedia NEWS が報じています[19]。同議員は、Visa が「本社は基準を決めているのみで、判断を行っていない（判断を行うのは現場）」と説明したことも公表しています[19]。これは Visa 自身の公式発表ではなく、議員の投稿にもとづく報道です。

一方で、止まった事例の多くは理由が公表されておらず、ブランド、アクワイアラー、決済代行会社のどこが、どの規則で判断したのかは、外からは確かめられません。カードブランドの規則の条文は、この解説では扱いません。確かなのは、取り扱いの可否が、ブランド、アクワイアラー、決済代行会社それぞれの規則と判断によること、そして法律が表現内容を決めているわけではないことです。

理由が開示されにくい

上の表の事例では、停止の理由が非公表のものがありました。加盟店契約の内容や審査の基準は、各社が公開していないのが通常です[8]。お店の側からは、何が基準で、どこで判断されたのかが見えにくく、事前に確かめにくいのが実情です。

また、この解説は、カード会社や決済代行会社の判断が正しいか誤りかを論じるものではありません。ここでは、判断の理由が外から見えないという構造と、その中でお店がどう備えるかに絞って説明します。

国や政治の動き

2023年3月9日の参議院内閣委員会で、経済産業省の審議官は、割賦販売法には「取扱商材の表現内容に関する規制というものは特に設けてはございません」と答弁しました[9]。

2024年12月27日には、衆議院議員の質問主意書（同年12月17日提出）に政府が答弁しました。政府は事例の情報を得ているとしたうえで、独占禁止法の優越的地位の濫用に当たるかどうかは「一概にお答えすることは困難」と答えています[10]。

2026年9月18日にデジタル大臣政務官に任命された赤松健氏は、10月15日、クレカ問題（創作物の表現規制の件）について、代替手段の検討を含めて様々な解決策を研究する観点から、何社かにヒアリングしている、と X で公表しました。その一社として、同日に株式会社 JPYC の岡部代表取締役と会談したとしています[11]。政務官としてのヒアリングの報告で、合意や政策が決まったという内容ではありません。

これらの動きは、国がこの問題を把握し、意見を聞いている段階にあることを示しています。2026年11月9日時点で、書き手が確かめられた範囲では、カード会社の取り扱いを国が変えさせる制度や、特定の決済手段を国が推奨する取り決めは見つかっていません。販売者は、制度が変わるのを待つのではなく、いま使える手段で備える必要があります。

法律で違法になる範囲

表現物の販売には、決済手段にかかわらず、法律で違法になる範囲があります。代表的なものは次のとおりです。

  • 刑法第175条（わいせつ物頒布等）[12]。
  • 児童買春、児童ポルノに係る行為等の規制及び処罰並びに児童の保護等に関する法律の第7条（児童ポルノの提供、製造、所持等）。定義は第2条第3項[13]。
  • 著作権法第119条（著作権侵害の罰則）。親告罪とその例外は第123条[14]。

これらは、カードでも、銀行振込でも、ステーブルコインでも違法です。決済手段を変えても、違法な表現物が適法になることはありません。このほか、都道府県の青少年健全育成条例による、未成年への販売の規制などもあります。この解説では個別の条例には触れていないため、販売する地域の条例は、各自でご確認ください。

反対に、法律に反しない作品の決済が、法律の外の理由で止まることがあります。この解説が扱うのは、そちらです。

自分の作品が、違法になる範囲に入るかどうかの判断は、条文だけでは難しいことがあります。迷うときは、弁護士などの専門家に相談してください。決済手段を変える前に、まず作品そのものが法律に反しないかを確かめることが、どの手段を使うときにも土台になります。

同人・成人向け作品の販売者が決済を確保するには

すてぶるくん：止まったときは、どうする？

すてぶるちゃん：決済手段を一つに頼らないこと。仕組みの違う手段を、複数並べておきます。申込先の取扱方針の確認と、止まったときの案内も、前もって用意します。

決済が止まる理由は、販売者の側では決められません。できるのは、止まったときに売り場が閉じないように備えることです。

  • 決済手段を一つに頼らない。カード、銀行振込、コンビニ払い、ステーブルコイン決済など、仕組みの違う手段を複数並べます。カードの中でも、ブランドや決済代行会社が一社に偏らないようにします。選び方はネットショップの決済方法の選び方にまとめています。
  • 申込先の取扱方針を事前に確かめる。申し込む前に、扱う作品の種類が対象になるかを、規約や問い合わせで確認します。取り扱いの可否と条件は、申込先ごとに違います。審査の考え方は決済代行に審査なしはある？で説明しています。
  • 止まったときの案内を用意する。代わりの決済手段と手順を、購入者向けのページにまとめておきます。告知の文面も、前もって決めておくと慌てません。

カードが止まったときの、代わりの決済手段を表にまとめます。条件は、使う決済サービスや契約で変わります。

銀行振込は入金の確認の手間があり、コンビニ払いは決済代行会社などとの契約が要るなど、どの手段にも条件があります。向き不向きを見て組み合わせてください。

たとえば、同人誌の通販のように、注文のたびに発送の作業がある販売では、入金を確認してから発送する銀行振込でも運用しやすいでしょう。ダウンロード販売のように、支払いのあとすぐに商品を渡したい販売では、入金の確認を待つ手段は向きにくく、すぐに支払いが済む手段を一つは用意したいところです。自分の販売の形に合わせて、並べる手段を選んでください。

申込先の取扱方針を確かめるときは、次の点を見ておくとよいでしょう。扱う作品の種類が取り扱い対象かどうか。取り扱いを止める条件と、止めるときの通知の方法。止められたあとの売上の精算がどうなるか。これらは、規約に書かれていることもあれば、問い合わせで答えが返ることもあります。書面や記録に残る形で確認しておくと、あとで見返せます。

購入者への案内は、短く具体的にします。たとえば「カードがご利用いただけない場合は、銀行振込、コンビニ払い、ステーブルコイン決済をお選びください。手順は下のページにあります」のように、代わりの手段と、手順のページへの行き先を一緒に示します。止まった理由を、販売者の側で推測して書く必要はありません。分からないことを断定せず、事実と手順だけを伝えるほうが、購入者にも誤解を与えません。購入者がいちばん困るのは、どう払えばよいか分からなくなることです。注文の途中で止まってしまった人に向けて、問い合わせ先も添えておくと、取りこぼしを減らせます。

ステーブルコイン決済（JPYC）の場合

すてぶるくん：ステーブルコインなら、止まらない？

すてぶるちゃん：止まらないとは言えません。JPYC の利用規約には、利用を停止できる条項があります。カードとは、止まりうる場所と、判断する会社が違います。

JPYC の利用規約（2025年10月24日制定、2026年9月24日最終改定）の第17条は、相手方の同意を得て JPYC を移転し、代価の弁済に使える形を定めています。この規約に、加盟店契約の仕組みはありません。カード決済のように、アクワイアラーや決済代行会社が加盟店を調べて契約する流れとは、仕組みが違います[15]。ステーブルコイン決済の基本はステーブルコイン決済とはで説明しています。導入の流れはJPYC 決済をお店に導入するにはにまとめています。

一方で、同じ規約は、第24条1項で禁止行為を定めています。公序良俗に反する行為、知的財産権の侵害、「当社が不適切であると判断する一切の行為」などが含まれます。第22条2項は、合理的な理由があれば通知なしで利用を停止でき、その理由は開示しないと定めています。合法なコンテンツの取引を制限しないという条項は、この規約にはありません[15]。ステーブルコイン決済にも、提供元の規約に基づく停止の可能性はあります。

JPYC の岡部典孝代表は、個人の X アカウントで次のように述べています。会社の規約やリリースではなく、同氏の発言です。

  • 2026年6月14日：「JPYCを用いた決済はJPYC社に加盟店管理義務が無く、我々は表現者と閲覧者の決済送金に関与しません。」[16]
  • 2026年10月28日：「JPYCは金融検閲に反対します。」[17]

カード決済と比べた違いを整理すると、カードでは、ブランド、アクワイアラー、決済代行会社という複数の会社が、お店との契約を通じて取り扱いを決めます。JPYC そのものの移転は、規約の形のうえで、払う人と受け取る人の合意によるもので、お店との加盟店契約を結ぶ会社が間に入りません[15]。その代わり、JPYC を発行する会社の規約と、JPYC を交換・保管するサービスの規約が、それぞれ利用の条件になります。JPYC を使う決済サービスを利用する場合は、そのサービスの契約条件も加わります。どちらの仕組みにも、止まる可能性がまったくないわけではなく、止まりうる場所と、その判断をする会社が違う、ということです。

購入者側にも条件があります。JPYC は居住者のみ、日本国内からのみ利用できる、と規約に定められています[15]。

すてぶるペイの考え方

すてぶるペイは、円で払い、ステーブルコイン（JPYC）で受け取る決済です。開発中で、提供開始日は未定です（2026年11月時点）。すてぶるペイの表現についての方針は、次のとおりです。「日本の法律で違法でない表現は、内容を理由に断りません。表現の良し悪しを決めるのは、決済会社ではありません。」利用には、利用規約への同意と法令上の要件を満たすことが前提で、利用規約では、日本の法律で違法な事業者ではないことを表明していただきます。刑法175条、児童ポルノ禁止法、著作権侵害などの違法な表現物は、どの決済手段でも違法で、取り扱えません。受け取る JPYC の利用は、JPYC 株式会社の利用規約に従います（同規約には、公序良俗違反などでの停止条項があります）。すてぶるペイが約束できるのは、自社の判断の範囲だけです。方針の全文は表現に関するすてぶるペイの方針にあります。

よくある質問

なぜカード会社は成人向け作品の決済を止めるのですか？

理由が公表されていない事例が多く、一律には言えません。カード決済は、国際カードブランド、アクワイアラー、決済代行会社を通る仕組みで、その各社の規則と判断で取り扱いが決まります。割賦販売法は取扱商材の表現内容を規制していない、と経済産業省は国会で答弁しています。

クレカの表現規制は、どこが決めているのですか？

一つの会社に決まっていません。国際カードブランド、加盟店と契約するアクワイアラー、契約を取り次ぐ決済代行会社が、それぞれの規則と判断で取り扱いを決めます。どこか一社が取り扱いをやめると、その先のお店ではカードが使えなくなります。割賦販売法は、取扱商材の表現内容を規制していません。

FANZA や DLsite で Visa が使えなくなったのはなぜですか？

理由が公表されていない事例が多く、一律には言えません。DLsite は2024年4月3日に Visa と Mastercard を、FANZA 同人は2024年6月14日に Visa を停止しました。カード決済は、国際カードブランド、アクワイアラー、決済代行会社の規則と判断で取り扱いが決まるため、どの会社の判断だったのかは、外からは確かめられません。

割賦販売法は表現を規制していますか？

経済産業省の審議官は2023年3月9日の参議院内閣委員会で、割賦販売法には取扱商材の表現内容に関する規制は特に設けていない、と答えました。法律とは別に、カード会社や決済代行会社が自社の規則と判断で取り扱いを決めています。

同人誌の通販で、カード以外に何が使えますか？

銀行振込、コンビニ払い、ステーブルコイン決済などがあります。コンビニ払いも決済代行会社などとの契約が要り、提供元が取り扱いを認めないことがあります。一つに頼らず、複数を並べ、申し込む前に取扱方針を確かめておくと、止まったときに備えられます。

JCB なら使えますか？

事例によります。DLsite が2024年4月に Visa と Mastercard を停止したときは、同社は JCB を利用可能としていると報じられました。どのブランドがいつ止まるかは、外からは分かりません。一つのブランドに頼らず、カード以外の手段も並べておきましょう。

ステーブルコイン決済なら、止められませんか？

止められないとは言えません。JPYC の利用規約には加盟店契約の仕組みがなく、払う人と受け取る人の合意で移転する形です。ただし JPYC 社の規約には、公序良俗に反する行為などを禁止し、利用を停止できる条項があります。カードとは仕組みが違うだけで、どこからも止まらないわけではありません。

すてぶるペイで成人向け作品を売れますか？

すてぶるペイの方針は「日本の法律で違法でない表現は、内容を理由に断りません。表現の良し悪しを決めるのは、決済会社ではありません。」です。ただし、刑法175条（わいせつ物頒布等）、児童ポルノ禁止法、著作権侵害などの違法な表現物は、どの決済手段でも違法で、取り扱えません。受け取る JPYC の利用は、JPYC 株式会社の利用規約に従い、同規約により利用が停止される場合があります。すてぶるペイは開発中で、提供開始日は未定です（2026年11月時点）。

カード会社が取り扱いを止めたとき、購入者にはどう案内すればよいですか？

別の決済手段を、購入画面や告知ページに前もって載せておきます。銀行振込の口座や手順、使えるコンビニ払い、ステーブルコイン決済の使い方を、一つのページにまとめておくと、止まった日にも案内を差し替えずに済みます。
