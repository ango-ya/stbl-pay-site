決済代行とは？仕組み・アクワイアラや収納代行との違い・選び方

決済代行（PSP）とは、お店と、カード会社・アクワイアラ・各決済手段との間に入り、契約・接続・入金をまとめて引き受ける事業者です。お店は、一つの契約と一つの入金窓口で、複数のカードブランドなどを受け付けられます。割賦販売法の登録と契約前の加盟店調査の義務は、加盟店契約を最終的に決める権限を持つ事業者（アクワイアラー、またはその権限を任された決済代行会社）にあります。選ぶときは、対応する決済手段、入金サイクル、総コスト、連携のしやすさを見比べます。カード以外の受け取り方として、ステーブルコイン決済もあります。

決済代行とは？（PSP とは）

決済代行とは、お店に代わって、カードなどの決済手段をまとめて提供するサービスです。事業者は「決済代行会社」や「PSP」（Payment Service Provider）と呼ばれます。お店とアクワイアラーとの間に入り、加盟店の申込、決済の処理、入金までを引き受けます[4]。

お店が自分でカード会社と契約すると、ブランドごとに申込と審査が要り、入金の日もばらばらです。決済代行を使うと、複数のカードブランドを一括で取り扱え、売上は決済代行会社からまとめて入金されます。QR コード決済や電子マネーを合わせて導入できる場合もあります[4]。

決済代行の仕組みとお金の流れ

カード決済には、購入者とお店のほかに、イシュア（カード会社）とアクワイアラーが関わります。購入者がカードで払ったときの流れは、次のとおりです[4]。

  1. 購入者が、お店でカードを使って払います。
  2. アクワイアラーが代金を立て替え、決済手数料を差し引いた金額をお店に入金します。決済代行を使う場合は、決済代行会社が入金を担うことがあります。
  3. アクワイアラーから、取引の情報がイシュアに送られます。
  4. イシュアが購入者に代金を請求します。
  5. 購入者が、イシュアに代金を支払います。

決済手数料の一部は、国際ブランドのライセンスフィーやネットワークの利用料などに充てられます[4][6]。各社への配分は、会社や契約で違います。お店から見ると、窓口は決済代行会社の一つだけです。

アクワイアラ・イシュア・国際ブランドとの違い

名前が似ていて混ざりやすいので、役割を表にまとめます。

カード決済に関わる会社と役割
呼び名 役割
アクワイアラー（加盟店契約会社） 加盟店と契約し、加盟店の管理を行います。代金を立て替える役割も持ちます[4]。
イシュア（カード発行会社） カード会員と契約し、カードを発行します。会員に代金を請求します[4]。
国際ブランド（カードブランド） Visa、Mastercard、JCB などです。どのブランドを使うかは、事業内容や客層で決めます[4]。
決済代行会社 アクワイアラーへの加盟店申込を代わりに行い、複数のブランドを一括で扱います[4]。

決済代行会社は、アクワイアラーの代わりに窓口になる会社です。契約書で、どの会社がお店と契約を結ぶ相手なのか、入金はどの会社から届くのかを確かめましょう。

アクワイアラーと直接契約する場合との違い

カード決済の導入には、大きく 2 つの方法があります[4]。

  • アクワイアラーと直接契約する。加盟店の申込と審査を、アクワイアラーごとに行います。複数のカードブランドを導入するときは、ブランドごとに交渉と契約の手続きが要ります。入金サイクルも会社ごとに違うため、入金の確認も別々になります。
  • 決済代行会社を使う。複数のブランドを一括で取り扱え、売上はまとめて入金されます。窓口は一つです。

お店の規模や、扱う決済手段の数で向き不向きが変わります。決済手段が少なく、手続きの手間を気にしないなら、直接契約も選択肢です。複数の手段を早くそろえたいなら、決済代行が向きます。

決済代行と収納代行の違い

収納代行は、購入者が商品代金を払うときの、支払いの回収を代行するサービスです。ネットショップが払込票を送り、コンビニや金融機関で払ってもらう仕組みが代表です[5]。決済代行は、契約から入金管理までの手続きを代行します[5]。

決済代行と収納代行の違い（一般的な傾向）
項目 決済代行 収納代行
主な決済手段 クレジットカード、電子マネー、QR コードなど幅広い[5] コンビニ決済や後払いなど、主に現金払い[5]
手数料の負担 通常は、お店が負担します[5] お店が負担する場合も、購入者が上乗せして払う場合もあります[5]
代行する内容 契約から入金管理までの手続き[5] 代金の支払いの回収[5]

サービスの範囲は会社ごとに違うため、申し込む前に、対応する決済手段を確かめてください。

割賦販売法の登録と加盟店調査

カード決済では、お店にカード番号等を取り扱わせる契約を結ぶ事業者は、割賦販売法で、経済産業省の登録を受けなければなりません。登録を受けた事業者が、「クレジットカード番号等取扱契約締結事業者」です[1]。経済産業大臣は、登録簿を一般の閲覧に供することになっています[1]。経済産業省は、登録事業者の一覧もウェブで公表しています[2]。

登録を受けた事業者は、契約を結ぶ前に、お店がカード番号等を適切に管理でき、不正利用を防げるかを調べます。契約後も、定期的に、または必要に応じて調べます[1]。決済代行会社が間に入る場合、登録が要るのは、契約上、加盟店契約の締結を最終的に決める権限を持つ側です。決済代行会社がアクワイアラーから包括的に任されて最終的に決め、加盟店を管理するなら決済代行会社が、一次審査などにとどまり最終的な決定をアクワイアラーが持つなら、アクワイアラーが登録を受けます[3]。

決済代行を選ぶときは、加盟店契約の相手が誰か（決済代行会社かアクワイアラーか）と、その相手が登録を受けているかを、契約書とこの一覧で確かめられます。審査の考え方は決済代行に審査なしはある？、審査に通らないときの見直しはクレジットカード決済の加盟店審査で解説しています。

決済代行のメリット・デメリット

お店から見た、一般的なメリットとデメリットです。

  • メリット：窓口が一つになる。複数のカードブランドを一括で導入でき、入金の窓口も一つにまとまります[4]。
  • メリット：決済手段を足しやすい。カードに加えて、QR コード決済や電子マネーを合わせて導入できる場合があります[4]。
  • メリット：早く始められることがある。急ぎの導入や乗り換えに向くとされ、審査が最短で当日から受け付けられる会社もあります[4]。
  • デメリット：会社ごとに条件が違う。取り扱うブランド、入金サイクル、入金手数料、システム利用料は、会社で違います[4]。
  • デメリット：費用が分かりにくいことがある。決済手数料を「要問い合わせ」としている会社も多く、料金の見えやすさに差があります[4]。
  • デメリット：審査がある。カードを扱う以上、契約前の調査は避けられません[1]。

決済代行の費用の項目と、手数料の消費税

費用は、会社ごとに項目も金額も違います。見積もりでは、次の項目を並べて確かめます[4][6]。

  • 初期費用：申込手数料や、決済端末の購入費用などです。オンライン決済では端末費用がかからないこともあります。
  • 月額費用：システム利用料などとして、毎月かかる会社があります。
  • 決済手数料：業種、規模、扱う商品で変わります。会社によっては要問い合わせです。
  • 振込手数料：売上金を振り込むときの費用です。即時入金には所定の手数料がかかる場合があります。
  • 入金サイクル：入金が早いほど資金繰りは楽になります。入金のたびに手数料がかかるかも確かめます。

料率の相場は、この解説では書きません。公開されている料率の多くは、販売する会社が自社の案内に載せたもので、お店の条件での結果とは限らないためです。見積もりの取り方と総コストの見方は決済手数料の比べ方にまとめています。

決済手数料にかかる消費税については、国税庁の質疑応答事例「クレジット手数料」が、信販会社の場合を説明しています。信販会社が加盟店から譲り受ける債権の額と、加盟店への支払額との差額は、消費税法施行令第10条第3項第8号に該当し、非課税とされています。これは令和7年8月1日現在の法令等に基づく、一般的な取扱いです。個別の事案では、異なる課税関係になることがあるとされています[7]。決済代行会社の手数料の扱いは、契約の内容と請求書の区分で確かめ、迷うときは税理士などに相談してください。

決済代行の選び方チェックリスト

申し込む前に、次の点を比べます。個人事業主の場合は、対象の事業形態と必要書類も、各社の案内で確かめます。決済代行会社は幅広い業種を受け入れる傾向があり、個人事業主や開業したての事業者にも望みがあるといわれます[8]。

  • 対応する決済手段。カードのブランド、QR コード、電子マネー、コンビニ払いなど、客層に合うものがあるか。
  • 対応する業種。自分の商品やサービスを扱えるか。取り扱えない業種の条件はどうか。
  • 入金サイクル。入金の頻度と、振込手数料の有無。
  • 総コスト。初期費用、月額、決済手数料、振込手数料を合わせて、月の売上でいくらになるか。
  • API や EC カートとの連携。使っているカートや、自社のシステムにつなげられるか。
  • サポート。問い合わせの窓口、対応の時間、サポートの費用。
  • 契約の相手と登録。加盟店契約を結ぶ相手は誰で、割賦販売法の登録を受けているのは誰か。登録事業者の一覧で確かめられます[2]。

カード以外も含めた決済手段の選び方は、ネットショップの決済方法の選び方で扱います。導入の手順はクレジットカード決済の導入、カード決済で起きる取り消しはチャージバックとはを見てください。

カード決済以外の受け取り方：ステーブルコイン決済

決済代行は、主にカードなどの決済を扱います。それとは別に、ステーブルコインで受け取る方法があります。ステーブルコインは、日本円などと価値が連動するように作られたデジタルのお金です。日本円と連動する例が JPYC で、発行体の JPYC 株式会社は、日本円と 1：1 で交換できるとしています[10]。日本では、一定の要件を満たすものが、資金決済法の「電子決済手段」にあたります[9]。

カードのような立て替えはなく、購入者は持っている残高から払います。そのため、カードの加盟店審査の仕組みとは別になります。ただし、購入者がステーブルコインを用意する必要があり、後払いや分割払いは、ふつうありません。仕組みはステーブルコイン決済とはで説明しています。

よくある質問

決済代行とは何ですか？

お店と、カード会社・アクワイアラ・各決済手段の間に入り、契約・接続・入金をまとめて引き受ける事業者（PSP）です。お店は、複数のカードブランドを一括で導入でき、入金の窓口も一つにまとめられます。

決済代行とアクワイアラの違いは何ですか？

アクワイアラ（加盟店契約会社）は、お店と契約を結び、代金を立て替える会社です。決済代行は、お店の代わりにアクワイアラへの申込をまとめ、複数の決済手段を一括で扱います。

決済代行と収納代行は何が違いますか？

決済代行は、カード・電子マネー・QR コードなど幅広い決済手段の契約から入金管理までを代行します。収納代行は、コンビニ払いなど、現金払いの代金の回収を代行するサービスです。手数料を購入者に上乗せできるかどうかも、サービスで違います。

個人事業主でも決済代行を使えますか？

申込の条件は会社ごとに違います。決済代行会社は幅広い業種を受け入れる傾向があるとされ、個人事業主にも望みがあるといわれますが、審査はあります。申し込む前に、対象の事業形態と必要書類を各社の案内で確かめてください。

決済代行の手数料にかかる消費税は、どう扱われますか？

国税庁の質疑応答事例は、信販会社の場合について、加盟店から譲り受ける債権の額と加盟店への支払額の差額を非課税としています。決済代行会社の手数料の扱いは、契約の内容と請求書の区分で確かめ、迷うときは税理士に相談してください。

決済代行を選ぶときは、何を見ればよいですか？

対応する決済手段、受け入れられる業種、入金サイクル、初期費用・月額・決済手数料・振込手数料を合わせた総コスト、API や EC カートとの連携、サポートを見ます。料率の見方は決済手数料の比べ方で説明しています。
