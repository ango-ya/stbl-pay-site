# 解説ページのサムネイル：Astra に渡すプロンプト

2026-11-09 作成。配信はしない（marketing/ はビルドの対象外）。

## 使い方

1. 毎回、キャラクターの参照画像を添付する。
   - すてぶるちゃん：`assets/char/kit/suteburu-chan.zip` の `chan_Y1_1.webp`（3/4 向きのバストアップ）と `chan_Y5F_1.webp`（全身）
   - すてぶるくん：`assets/char/kit/suteburu-kun.zip` の `kun_K2_1.webp`（体）と `kun_YK2_7.webp`（表情）
   - 設定資料（video-studio の `assets/char/src/sheet_chan.png`・`sheet_kun.png`）が手元にあれば、それも添付する
2. 下の「共通ルール」を先頭に貼り、そのあとにページごとの「場面」を貼る。
3. 各 2〜3 枚作り、キャラの崩れがいちばん少ないものを選ぶ。
4. 選んだ画像は `marketing/thumbnails/in/<slug>.png`（例 `in/payment-gateway.png`）に置く。題名・ロゴ・ラベルはコードで重ねて、OGP（1200×630）と記事の冒頭の画像を書き出す（`scripts/learn-thumbs/`）。

## 共通ルール（毎回、先頭に貼る）

```text
解説記事のサムネイル用のイラストを 1 枚描いてください。

【大きさと構図】
・横 16:9（1920×1080 以上、できれば 3840×2160）。
・画面の左 55% は、あとから題名の文字を重ねる場所です。左側には人物や細かい物を置かず、淡い背景と、大きくぼかした形だけにしてください。
・キャラクターと主役の小道具は、画面の右 45% にまとめる。キャラクターの頭が上端で切れないこと。
・四隅から 5% は、大事なものを置かない余白にする。

【画風と色】
・添付の設定資料のキャラクターと同一人物・同じ衣装・同じ配色・同じ画風（太めの紺の輪郭、白と青が主役のフラットな塗り、やわらかい陰影）。
・配色：メインブルー #2563FF／ライトブルー #7EC6FF／シルバー #EBEEF7／ネイビー #0F206B／ホワイト #FFFFFF。背景は #F6F7FB〜#EAF2FF の明るい色を基調に、差し色はメインブルー 1 つ。
・明るく清潔で、やさしい雰囲気。写真風・3D・グラデーションのギラつき・グロー・レンズフレア・キラキラ・集中線は使わない。

【文字の禁止】
・画像の中に文字・数字・記号・ロゴ・透かし・吹き出し・看板の文字を一切入れない（¥ や $ や % の記号も描かない）。服の「すてぶるペイ」ロゴと、すてぶるくんのおなかの「す」だけは設定資料どおり。崩れるなら無地でよい。
・画面・書類・本・カードの表面は、文字の代わりに、色のついた帯や丸や四角の模様で表す。

【キャラクターの決まり】
・左右反転した絵にしない。すてぶるちゃんのリボンとヘアピンは設定資料と同じ側（本人の左）、すてぶるくんのおなかの「す」は正しい向き。
・すてぶるちゃんは、説明する側。上半身か全身を正面寄りで描く。スカートの中が見えるポーズや下からのアングルにしない。
・すてぶるくんは、白くて丸い体で宙に少し浮いている。平熱の表情（真顔・ぽかん・半目）。大げさに笑わない。
・二人とも、お金・硬貨・お札・クレジットカード・スマホを手に持たない（小道具は二人の近くに浮かべるか、台の上に置く）。
・表情は大げさにしない。怒鳴る顔・泣き顔・汗や血管マークは描かない。
・恋人・親子・主従に見える距離感にしない。並んで同じものを見ている構図が基本。

【実在のものを描かない】
・実在の会社・カードブランド・銀行・アプリのロゴや画面を描かない。カードは無地の青いカード、スマホやパソコンの画面は色の帯だけ。
```

## ページごとの場面（共通ルールのあとに貼る）

### stablecoin-payments（ステーブルコイン決済とは）

```text
【場面】右側に、円の形をした大きな青いコイン（表面は模様だけ）が宙に浮かび、そこから細い光の線が、小さなお店の建物のアイコンへ伸びている。すてぶるちゃんは手のひらを上に向けて、そのコインを示している（説明する顔）。すてぶるくんはコインの横に浮かんで、ぽかんとコインを見上げている。
```

### jpyc-payments（JPYC 決済をお店に導入するには）

```text
【場面】右側に、小さなお店のカウンター。カウンターの上にタブレットが立っていて、画面には大きな青い丸の中に白いチェックマーク（完了の印）だけが映っている。すてぶるちゃんは人さし指でタブレットを指している。すてぶるくんはカウンターの端からのぞきこんでいる。
```

### card-merchant-screening（クレジットカードの加盟店審査に通らないときの選択肢）

```text
【場面】右側に、無地の大きな青いクレジットカードが、閉じたゲート（柵）のように立っている。その手前に、色の帯だけの書類が何枚か積まれている。すてぶるちゃんはあごに手を当てて考えている。すてぶるくんは書類の山を見上げて、半目になっている。
```

### no-screening-payments（決済代行に審査なしはある？）

```text
【場面】右側に、明るく開いた扉（ドア）。扉の向こうは、やわらかい光の明るい空間。すてぶるちゃんは手のひらを上に向けて、扉のほうを示している。すてぶるくんは扉の前に浮かんで、向こう側をのぞいている。扉の脇に、小さな盾の形のアイコンが 1 つ浮かんでいる（規約と法令の前提を表す）。
```

### payment-fees（決済手数料の比べ方）

```text
【場面】右側に、大きな天びん。左右の皿に、大きさの違う青と水色の積み木（模様だけ）が載っている。そばに、ボタンだけの無地の電卓が浮かんでいる。すてぶるちゃんはあごに手を当てて天びんを見比べている。すてぶるくんは電卓の横に浮かんで、真顔で電卓を見ている。
```

### chargeback（チャージバックとは）

```text
【場面】右側に、色の帯だけのレシートの紙が、くるりと弧を描いて小さなお店の建物のアイコンへ戻ってくる（ブーメランのような軌道を、点線で示す）。すてぶるくんは目を少し見開いて、戻ってくる紙を見ている。すてぶるちゃんは真顔で、人さし指を顔の横に立てている（大事なところ、の仕草）。
```

### glossary（ステーブルコイン決済の用語集）

```text
【場面】右側に、開いた大きな本（ページは色の帯だけ）。本から、小さなアイコンのカードがいくつか浮かび上がっている（鍵、盾、丸いコイン、建物、矢印）。すてぶるちゃんは顔の横に人さし指を立てている。すてぶるくんは浮かんだカードの 1 枚を、ぽかんと見ている。
```

### what-is-stablecoin（ステーブルコインとは）

```text
【場面】右側に、まっすぐ水平につり合ったシーソー。片側に青い丸いコイン（模様だけ）、反対側に紙のお札の形（無地の帯）が載っていて、ぴったり同じ高さ。すてぶるちゃんは手のひらを上に向けて、つり合っていることを示している。すてぶるくんはシーソーの真ん中の上に浮かんで、半目で左右を見比べている。
```

### payment-gateway（決済代行とは）

```text
【場面】右側に、まん中の大きな丸いハブ（青い円）から、何本もの線が放射状に伸び、先に小さなアイコンがつながっている（無地のカード、建物、スマホ、コンビニの建物の形）。反対側の 1 本は、小さなお店のアイコンにつながっている。すてぶるちゃんは人さし指でハブを指している。すてぶるくんは線の 1 本の上に浮かんで、線の先を見ている。
```

### accept-credit-cards（ネットショップでクレジットカード決済を導入するには）

```text
【場面】右側に、ノートパソコン（画面は色の帯とボタンの形だけ）と、そこへ向かう 3 つの丸い飛び石の道。飛び石の最後に、白いチェックマークの青い丸。すてぶるちゃんは胸の前で小さくこぶしを握っている。すてぶるくんは飛び石の 2 つめの上に浮かんでいる。
```

### online-payment-methods（ネットショップの決済方法の選び方）

```text
【場面】右側に、小さな棚。棚には、いろいろな決済方法を表すアイコンが並んでいる（無地の青いカード、コンビニの建物、銀行の建物、QR コード風の四角い模様のスマホ、丸い青いコイン、配達の箱）。すてぶるちゃんは手のひらを上に向けて、棚を紹介している。すてぶるくんは棚の前に浮かんで、どれにしようか真顔で見比べている。
```

### card-expression-restrictions（カード会社の表現規制はなぜ起きる？）

```text
【場面】右側に、絵を描く人の机。机の上に、スケッチブックと、描きかけの漫画のコマ割りの紙（中身は色の帯と丸だけ。人物も描かない）。机の端に、無地の決済端末があり、小さな赤いランプが 1 つ点いている。すてぶるちゃんは小声で困った顔（眉が少し下がる）。すてぶるくんは、スケッチブックをぽかんと見ている。性的な表現・肌の露出・暴力は一切描かない。
```

### policy-expression（表現に関するすてぶるペイの方針）

```text
【場面】右側に、大きな額縁がいくつか並んだ明るい壁（額の中身は、色の違う抽象的な形や模様だけ。風景・人物・性的な表現は描かない）。すてぶるちゃんは決めポーズ：本人の右手を向かって左へ差し伸べる。すてぶるくんは青い座布団の上に、真顔で浮かんでいる。
```
