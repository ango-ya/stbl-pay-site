# 外部施策の下書き

`marketing/seo-strategy.md` の §5「サイトの外でやること」の下書き。公開・送信は、ユーザー本人が判断して行う。下書きの作成者は、投稿・送信・アカウント操作をしていない。

どの下書きでも、サービスの説明は「円で払い、ステーブルコイン（JPYC）で受け取る決済（開発中）」にそろえている。手数料の料率と提供開始日は書いていない（手数料は「検討中。全加盟店一律の固定料率を予定。購入者への上乗せなし」）。

## 出す前にユーザーが確かめること

### 事実

- 提供状況の文言（「開発中」「提供開始日は未定」）が、出す日にも正しいか
- Sandbox の URL と始め方が、いまも合っているか（docs/testing/sandbox.md）
- zenn-article.md のコードが、現行の docs と OpenAPI（/docs/openapi.yaml）と一致しているか。署名ヘッダーの名前は記事に書いていないので、読者向けに足すなら docs で確認する
- note-article.md の Stripe の 3.6%（国内カード）は、2026-11-05 に公式ページで確認した値。出す日に再確認する。他社の料率は書いていない
- press-release.md の会社概要・実績は、index.html のフッターのコメントにある出典（アステリア、QTnet、福岡市）で再確認する。事業内容の行は空欄
- JPYC に関する記述（JPYC 株式会社が発行、電子決済手段）が、最新の公式情報と合っているか。出典は解説ページ（/learn/jpyc-payments/ など）で一次資料を確かめたもの。出す日に JPYC 公式でもう一度確かめる

### 法務

- すてぶるペイの法的な位置づけは、どの下書きでも断定していない。電子決済手段等取引業にあたるかどうかは弁護士の確認が必要（marketing/research/facts.md に記載）
- JPYC は「JPYC 株式会社が電子決済手段として発行している」と書き、「法定通貨と連動するから電子決済手段」とは一般化していない（出典は本文に記載）。表現を変えるときは、リスクが無い・元本が守られるといった言い方にしない
- 比較サイトへの依頼が、広告やタイアップの契約になる場合は、条件を本人が読んで判断する
- note の記事は、他社を悪く言っていないか、最終の目で読む

### 社名表記

- 会社名は「合同会社暗号屋」（英語は Ango-ya LLC）に統一済み（2026-11-06。サイトのフッターと llms.txt も同じ表記）
- サービス名は「すてぶるペイ（STBLpay）」。読みは「ステーブルペイ」（llms.txt の英文）

### 連絡先

- press-release.md の問い合わせ先は「（記入）」のまま。会社名・担当者・メール・電話を入れる
- outreach-comparison-sites.md の送り先は、2026-11-05 にトップページで確認した範囲。メールアドレスはどこも見つからず「（要確認）」。フォームの現行 URL を開いて確かめる
- 署名の氏名・メールアドレスを入れる
- 記事に入れる URL（/learn/ の各ページ）は、公開後に開いて確かめる
