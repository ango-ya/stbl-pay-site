## リード

合同会社暗号屋（本社：福岡市）は、円で払い、ステーブルコイン（JPYC）で受け取る決済「すてぶるペイ（STBLpay）」（開発中）について、組み込みを試せる Sandbox、加盟店向けドキュメント、API 仕様書（OpenAPI 3.1）を公開しました。サービスの提供開始日は未定です。

## 本文

### 公開したもの

- **Sandbox**：組み込みを試すための環境です。本番とは別の環境で、JPYC の発行・償還を行う外部サービス「JPYC EX」の部分はモックに置き換えています。加盟店はパスキーで登録し、決済の作成から状態の照会までを試せます。
- **加盟店向けドキュメント**：決済の流れ、Quick Start、決済の状態、Webhook（署名の検証、重複の除外、再送）、返金の提供範囲、セキュリティを説明しています。英語版もあります。
- **API 仕様書（OpenAPI 3.1）**：加盟店のサーバーが呼ぶ API（決済の作成・状態の照会）と、Webhook の本文・ヘッダーを定義しています。英訳版もあります（正本は日本語版）。

### 公開した理由

すてぶるペイは開発中です。提供開始に先立って、組み込みの手順と API の形を公開し、ネットショップの開発者が早い段階で確かめられるようにしました。AI コーディングエージェントに仕様書を読ませて、組み込みを進めることもできます。

### 組み込みの考え方

加盟店のサイトでやることは 3 つです。

1. 加盟店のサーバーで決済を作る
2. 返ってきた決済ページの URL へ、購入者を移動させる
3. 加盟店のサーバーで結果を受け取る（Webhook または状態の照会）

支払いの承認は、すてぶるペイの決済ページで購入者が行います。署名の処理を加盟店が実装する必要はありません。WordPress（WooCommerce）向けのプラグインは準備中です。

### 背景

クレジットカード決済は、カード会社の加盟店審査の結果によって、導入できない場合があります。すてぶるペイは、カード会社の与信審査に頼らない決済として開発しています。加盟店は、利用規約への同意と法令上の要件を満たすことが前提です。

## サービス概要

| 項目 | 内容 |
|---|---|
| サービス名 | すてぶるペイ（読みは「すてぶるぺい」、英語表記 STBLpay） |
| 内容 | 円で払い、ステーブルコイン（JPYC）で受け取る決済（開発中） |
| 購入者の支払い | パスキー（顔・指紋認証）で承認し、日本円の銀行振込で支払う。JPYC 残高で足りるときは振込なし |
| 加盟店の受け取り | 決済と同時に JPYC で受け取る。日本円への引き出しは、加盟店自身の JPYC EX アカウントで行う |
| 設計 | ノンカストディアル（提供元は購入者・加盟店の資金や秘密鍵を保持しない） |
| 手数料 | 検討中。全加盟店一律の固定料率を予定。購入者への上乗せなし |
| 提供状況 | 開発中。提供開始日は未定 |
| 対象 | 個人事業主、クレジットカード決済の導入が難しいネットショップ、日本向け決済を持ちたい海外のネットショップ |
| サイト | https://stbl-pay.com/ |
| 加盟店向けドキュメント | https://stbl-pay.com/docs/ |
| API 仕様書 | https://stbl-pay.com/docs/openapi.yaml |
| Sandbox | https://stbl-pay.com/docs/testing/sandbox （始め方。公開前に URL を開いて確かめる） |
| 解説ページ | https://stbl-pay.com/learn/ （ステーブルコイン決済、JPYC 決済、決済手数料、チャージバックなどの解説） |
| プレスキット | https://stbl-pay.com/press/ （ロゴ、キャラクター、配色、サービスの説明文） |
