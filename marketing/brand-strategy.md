# すてぶるペイ ブランド戦略

2026-11-06 作成。配信はしない。検索と AI の戦略（`seo-strategy.md`）の上位にある考え方をまとめる。
前提として、社内の「2026年 マーケティング戦略とリソース配分」を踏まえる。
- 主戦場（P0）：高摩擦のデジタルプラットフォームと海外の FX
- 個人の決済（P1）：クリエイターなど
- 3 つの防壁：ノンカストディアル、自己導入、公式提携だけを法務で審査する

## 1. いまの状態

素材はそろっている。足りないのは、それを「仕組み」として外へ広げる部分である。

| ある | 無い |
|---|---|
| 日本語・英語の文字のロゴ（SVG）、色と書体のトークン、説明スライドのテンプレート | 小さく使える記号（シンボルマーク）。ボタン・アイコン・ファビコンに使えない |
| キャラクター（すてぶるちゃん・すてぶるくん）、つかいかた動画 8 本、4 コマ漫画の試作 4 話 | 加盟店のサイトに置く公式のボタンと「使えます」のマーク |
| LP、解説ページ、docs、Sandbox、OpenAPI | 報道向けの素材集、名前とロゴの使い方の決まり |
| 「円を使って、ステーブルで払う。」「Pay in yen. Settle in stablecoin.」 | どこでも同じ言い方をするための、サービスの短い説明の決まり |

## 2. 浸透したときの姿（めざす状態）

決済のブランドは、広告で広がるのではない。支払いの画面に並び、手で触れることで広がる。カードのブランドや「PayPay」「コンビニ払い」と同じで、「お支払い方法」の並びに名前が出ていることが、そのまま認知になる。

| 誰にとって | 浸透したときに頭に浮かぶこと |
|---|---|
| 購入者 | 「すてぶるペイで払う」というボタンを見ても迷わない。顔か指紋で承認する、円で払える、と知っている |
| 加盟店 | 「カード会社の審査に頼らずに、売上を円のステーブルコインで受け取れる決済」。カード会社の審査とは別の、すてぶるペイの規約と審査の考え方で判断される |
| 開発者 | 「ボタンを置く、画面へ案内する、結果を受け取る」の 3 つで組み込める。AI エージェントに docs を読ませても組み込める |
| 報道・業界 | 日本円のステーブルコインで、小さなお店が決済を受ける実例の代表 |

## 3. ブランドの核

- **約束：** 円で払える安心と、止められにくい受け取りを、小さなお店にも。
- **性格：** やさしい、まっすぐ、きちんとしている。
  - 煽らない。断定しすぎない。専門用語を押しつけない。
  - キャラクターの軽さで入口を作る。中身は正確さで信頼をつくる。
- **言葉の決まり：**
  - サービスの短い説明は、どこでも「円で払い、ステーブルコイン（JPYC）で受け取る決済」にする。開発中のあいだは「（開発中）」を添える。
  - キャッチコピーは日本語「円を使って、ステーブルで払う。」、英語「Pay in yen. Settle in stablecoin.」で固定する。
  - 名前は、日本語では「すてぶるペイ」、英語では「STBLpay」と書く。読みは「ステーブルペイ」（pronounced "stable pay"）。
    - 「すてぶる ペイ」と分けない。
    - 「ステーブルペイ」は読みとしてだけ使う。表記には使わない。
- **見た目の決まり：** 地は ink の #161616 と白。差し色は青の #2775ca。表紙などの大きな面には紺のグラデーションを使う。
  - 書体は、欧文が Schibsted Grotesk、和文がヒラギノ角ゴ。
  - ロゴは縦横比を変えない。色を足さない。影を付けない。

## 4. ブランドの構成

- **親ブランド：** すてぶるペイ / STBLpay
- **記号：** 新しく作る（今回、案を出す）。ボタン、アイコン、ファビコン、ステッカーの共通の印にする。
- **加盟店マーク：** 「すてぶるペイ使えます」。EC サイトの「お支払い方法」の並びと、お店の入口・レジに置く。
- **公式ボタン：** 「すてぶるペイで支払う」。加盟店がそのまま貼れるコードとして配る。
- **キャラクター：** すてぶるちゃん・すてぶるくん。購入者向けの説明、動画、漫画、ステッカーと POP に使う。加盟店の業種の広告には使わない（§5）。
- **公式提携：** 「すてぶるペイ公式パートナー」。法務の審査を通った相手だけが名乗れる。

## 5. ブランドを守る仕組み

主戦場の業種（高摩擦のデジタルプラットフォームなど）は、決済の需要が強い。その反面、ブランドが業種の印象と結び付きやすい。ブランドは「適法な事業者の受け取りを支える、中立で、きちんとした決済」として守る。

- **加盟店マークとボタン：** 加盟店が自分で貼れる形で配る。ただし、使い方の決まり（縦横比、色、誤解を招く使い方の禁止）と、規約に反したときは使えなくなることを、配布ページに書く。
  - 規約の文言は法務が決める。配布ページはその規約にリンクする。
- **共同のマーケティングと「公式パートナー」の表示：** 法務の審査（相手の免許、法域、AML、資金の流れ）を通った相手に限る。これは成長戦略の「公式提携」の防壁と同じ線引きである。
- **キャラクター：** 購入者向けの説明と、すてぶるペイ自身の発信だけに使う。加盟店の商品・業種の広告に出さない。プレスキットでは、記事でサービスを紹介するときに限って使ってよい、と書く。
- **言葉：** 「誰でも」「必ず」「安全」「元本保証」は使わない。料率と提供開始日は、公表の承認が出るまで書かない（サイトのテストで止めている）。

## 6. 広がる仕掛け（自然に名前が届く場所）

| 仕掛け | 何が起きるか | 時期 |
|---|---|---|
| 公式ボタンと加盟店マークの配布（コードとロゴ） | 加盟店が増えるほど、支払いの画面に名前が並ぶ | 今回作る |
| お支払いの画面、完了の画面、通知のメール | 払った人が「すてぶるペイで払った」と覚える。完了の画面から LP・解説へ | 提供開始まで |
| 「使えるお店」の一覧（加盟店が載ることを選んだ場合） | 「jpyc 使えるお店」で検索する人に届く。加盟店にとっては集客になる | 提供開始後 |
| WordPress（WooCommerce）のプラグイン | プラグインの一覧で見つかる。公式ボタンがそのまま入る | 準備中のもの |
| キャラクターの連載（4 コマ漫画・動画） | 決済に興味のない人にも、名前と顔が届く。X で回る | 試作 4 話から始める |
| プレスキット | 記事のロゴと説明が正しくなる。AI が引用するときの正しい出典になる | 今回作る |
| 開発者向け（Zenn の記事、GitHub のサンプル、OpenAPI、llms.txt） | 「JPYC 決済 開発」で見つかる。AI エージェントが組み込み方を答えられる | 下書きあり |
| 導入事例（加盟店の声） | 「自分の業種でも使える」と分かる。報道の切り口になる | 最初の加盟店から |
| 展示会のチラシと、レジ横の POP | 地域の個人事業主に届く | チラシあり |

## 7. 進め方

1. **土台（今、提供開始前）**
   - 記号を決める。
   - 公式ボタンと加盟店マークを決めて、配布ページと docs に置く。
   - プレスキットを置く。
   - この文書の言葉の決まりを、サイト・下書き・スライドにそろえる。
2. **公開の波（プレスリリースの前後）**
   - PR TIMES で配信する。CoinPost とあたらしい経済には個別に相談する。
   - キャラクターの漫画の連載を始める。
   - 比較サイトに相談する。
3. **最初の加盟店（提供開始の前後）**
   - 導入事例を作る。
   - 加盟店マークを配る（ステッカーと POP）。
   - 「使えるお店」の一覧を作る。
   - お支払いの画面と完了の画面のブランドを整える。
4. **広がり**
   - 公式パートナーの表示を始める。
   - プラグインを出す。
   - 英語圏のお店向けに発信する。

## 8. 測り方

- **名前の検索：** Search Console で「すてぶるペイ」「STBLpay」「ステーブルペイ」の表示回数を見る。認知の一番正直な指標になる。
- **言及：** 第三者の記事と、X での言及。週次の点検で拾う。
- **AI の回答：** 固定の質問で、すてぶるペイが出るか（`target-keywords.md`）。
- **公式ボタンと加盟店マークの設置数：** 配布の手順に「設置したら知らせてください」を入れて数える。
  - ボタンの画像を stbl-pay.com から直接読み込ませれば、設置数を自動で数えられる。ただしその場合は、加盟店のサイトから購入者の情報（Referer など）が届く。この取り扱いを決めるまでは、自動では数えない。
  - 今の `_headers` は Cross-Origin-Resource-Policy: same-origin なので、他のサイトから画像を直接読み込むことはできない。直接読み込ませると決めたら、配布する素材のパスだけを外す。

## 9. 決めてもらうこと

1. 記号（シンボルマーク）の案のどれにするか
2. 公式ボタンのデザインと文言
3. 加盟店マーク・ボタンの使い方の決まりと、規約との関係（法務）
4. キャラクターの使ってよい範囲
5. 報道の問い合わせ先（広報の窓口）
