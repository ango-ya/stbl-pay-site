# お金の流れ

利用者は JPYC で支払い、加盟店は JPYC で受け取ります。JPYC 残高が足りない利用者は、先に JPYC EX で発行を申し込み、日本円を払い込んで JPYC を用意します。ここでは、JPYC が利用者から加盟店に届き、円に戻るまでを説明します。語の意味は[用語集](/reference/glossary)にあります。

## 使うもの

- **JPYC**：1 JPYC ＝ 1 円の、日本円建てのステーブルコインです。STBLpay の決済は JPYC で行います。
- **JPYC EX**：JPYC の発行と償還（円に戻すこと）を行う、発行体のプラットフォームです。利用者や加盟店は JPYC EX と直接やりとりし、STBLpay は間に入りません。
- **Polygon**：JPYC が動くブロックチェーンです。利用者のウォレットも、加盟店の受取ウォレットも Polygon 上にあります。

## 流れ

1. **利用者が JPYC を用意する。** JPYC 残高が足りない利用者は、JPYC EX で JPYC の発行を申し込み、銀行振込で円を払い込みます。振込が確認されると、JPYC EX が利用者のウォレットに JPYC を発行します。残高が足りる利用者は、この手順を飛ばします。
2. **利用者が支払いを承認する。** 利用者が決済ページでパスキーで承認すると、利用者のウォレットから加盟店の受取ウォレットへ JPYC が送られます。STBLpay の手数料は、同じ取引の中で差し引かれます。
3. **加盟店の受取ウォレットに JPYC が届く。** 届いた額（手数料を引いたあと）は、Webhook の `net_received_jpy` で確認できます。届いた JPYC は受取ウォレットに残り、[返金](/refunds/overview)の原資にもなります。
4. **加盟店が JPYC を円に戻す。** 受取ウォレットの JPYC を、JPYC EX で償還して円にします。加盟店コンソールの「引き出し」から JPYC EX の手続きへ進む形を予定しており、**現在は準備中です。**

例：利用者が 4,980 円の注文を、JPYC 残高 0 の状態で支払う場合

1. 利用者が JPYC EX で 4,980 円分の発行を申し込み、4,980 円を銀行振込する。
2. 利用者のウォレットに 4,980 JPYC が発行される。
3. 利用者がパスキーで承認し、4,980 JPYC から手数料を引いた額が、加盟店の受取ウォレットに届く。

## 受取ウォレット

- 加盟店ごとに 1 つある、Polygon 上のウォレットです。加盟店の owner のパスキーにひも付いています。
- アドレスは、Webhook の `payout` に入っています。
- ウォレットは、最初の決済のときに作られます（状態が `deploying` を経ます）。
- 受取ウォレットから JPYC を動かすには、owner のパスキーによる承認が必要です。STBLpay が単独で動かすことはできません。
