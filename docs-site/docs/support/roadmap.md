# 今後の予定

1st リリースのあとに提供を予定している機能です。時期と詳細が決まったら、このページでお知らせします。

## 複数アカウントでの管理

加盟店アカウントを、owner 以外のスタッフも使えるようにします。

- owner が招待 URL を発行して、スタッフに渡します。スタッフは自分の端末でパスキーを登録し、owner が承認すると使えるようになります。メールアドレスは使いません。
- owner は、スタッフごとに「返金」と「引き出し（償還）」をそれぞれ許可するかを選べます。対象の店舗と、返金 1 件あたりの上限も決められます。
- owner は、スタッフをいつでも外せます。外したスタッフは、その時点から操作できなくなります。

それまでは、加盟店コンソールの操作はすべて owner のパスキーで行います。

## WooCommerce プラグイン

WooCommerce のストアに、STBLpay を決済手段として追加するプラグインです。

- 決済の作成、決済ページへの移動、Webhook を受けて注文を確定する処理を、プラグインが行います。

それまでは、[既存 EC への結合](/client/integrate-existing-ec)のとおり、API で組み込んでください。
