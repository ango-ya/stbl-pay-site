# 返金の提供範囲

加盟店コンソールではownerがパスキーで返金を承認します。[加盟店サーバーからの返金](/refunds/machine-api)は公開準備中の仕様としてpreviewで確認する段階です。JPYC EXへの事前共有前であり、本番提供開始の案内ではありません。決済APIキーでは返金できません。

返金先は元の支払人に固定され、全額・一部・複数回の返金の合計は決済残額までです。元の決済は `settled` のままで、公開準備中の仕様では `refund.confirmed` と `refund.failed` で返金結果を通知します。受付は完了ではなく、通知未着時は照会で突合します。

[コンソールの手順](/refunds/execute)、[原資](/refunds/funding)、[エラー](/refunds/errors)を参照してください。
