# 返金の手順

返金は加盟店コンソールで行います。加盟店コンソールにログインしていることと、承認に使う owner のパスキーが必要です。

## 手順

1. 加盟店コンソールのホームから「店舗と API キー」を開き、対象の店舗の「取引」を開く。
2. 返金する取引の「詳細」を開き、「取引の詳細」画面の「返金」を確認する。
3. 「返金額（円）」に金額を入力する。全額を返すときは「全額」を押す（その時点で返金できる額が入る）。
4. 「返金する」を押す。サーバーが返金の操作を組み立てる。
5. 「返金を承認しますか？」のダイアログで、対象の注文番号と決済 ID、返金額、返金先を確認し、「パスキーで承認」を押す。
6. 画面の表示と「返金の履歴」で結果を確認する。

返金先は、その決済のお客さまの受取先に固定されています。ダイアログの返金先は確認用で、変更できません。承認前に取りやめるときは「やめる」を押します。組み立てたあとで承認していない返金は、「返金の履歴」の「承認待ちを取りやめる」で取りやめられます。

## 結果の確認

承認した返金は、まず受付済みになります。受付は完了ではありません。チェーン上で結果が確定して初めて「返金完了」になります。

| 履歴の状態 | 意味 |
|---|---|
| 受付済み（送信待ち） | 承認を受け付けた。まだ送信していない |
| 処理中 | 送信し、結果を待っている |
| 返金完了 | 確定した。返金額が確定返金額に入る |
| 失敗 | 返金されなかった。理由が履歴に出る |
| 結果確認中 | 結果をまだ判断できない |

通信の失敗や画面を閉じたことだけでは、返金が失敗したとは限りません。「結果確認中」や、承認後に結果が分からない間は、新しい返金を始めず、「再確認」で結果を確かめてください。画面を開き直しても、サーバーの記録から進行中の返金が再び表示されます。

履歴には、受付の時刻と確定の時刻が別々に出ます。全額を返金したあとも履歴は残ります。
