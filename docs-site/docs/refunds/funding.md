# 返金できる額と原資

「返金」の画面には、次の額が別々に出ます。

- **決済額**：元の決済額（手数料を引く前）
- **返金済み（確定）**：結果が確定した返金の合計。「返金済み」と言えるのはこの額だけ
- **確保中（受付済み・承認待ち）**：結果が確定していない受付済みの返金と、承認待ちの返金の合計
- **返金できる額**：決済額から、確定と確保中を引いた額
- **いま返金できる額**：返金できる額を、さらにチェーン上の上限と受取ウォレットの残高で絞った額。「全額」を押すと、この額が入る

返金の原資は、受取ウォレットの残高です。決済額は手数料を引く前の額ですが、加盟店の受取額は手数料を引いたあとです。**全額を返金するには、受取ウォレットに全額分の残高が必要です。** 残高が足りないと、「いま返金できる額」が下がり、画面に理由が出ます。原資を用意してから「再確認」を押してください。

## 額が下がる理由

「いま返金できる額」が「返金できる額」より小さいとき、画面に理由が出ます。

- **受取ウォレットの残高が不足している。** 原資を用意してから再確認する。
- **チェーン上の返金の裏付けが足りない。** 同じお客さまへの返金が先に行われた場合に起きる。返金できる額は、お客さまがそのウォレットへ支払った累計の範囲に制限される。

チェーン上の値を読めないときは、額を推測しません。「返金できる額」と「いま返金できる額」を出さず、「状況を確認できないため、今は返金できません。」と表示します。額が表示されたとき、それはサーバーが確認した値です。自社でキャッシュして、それだけを根拠に返金しないでください。
